# Problem 12.40: verification and provenance report

The proof constructs, for every k>=3, a simple finite group
PSL_6(5^a) with |G|_2=8192 and an irreducible 2-Brauer character of
degree 2-part exactly 2^k. Thus no finite-valued bound of the requested
form exists. Candidate 35 is complete as a mathematical deduction;
priority and independent review remain pending.

## Primary input

Bray's author PDF, dated 27 July 2007, states the absolutely irreducible
projective-heart representation used here in its Main Theorem. The
short paper's mathematical text was read; pages 2 and 3 were viewed
locally. The representation assertion and its proof were checked
against n=6, p=2 and q=5^a. The paper's cohomology computation is not
a premise of our result. The PDF, extracted text and relevant page
images are frozen. The Notebook's exact question was viewed on p.60
and that image is also included.

The representation family is credited prior work. The fixed Sylow
order and unbounded valuation deduction is proposed here; unsuccessful
priority searches do not establish that it is new. No third party
has been contacted.

## Arithmetic controls

`check_12_40.py` verifies all 510 lifts from k=3 through k=512,
including the unused exponent giving exact valuation k. An independent
root lift in q uses a sum of powers, while the exponent construction
uses Horner evaluation. Exhaustion for k=3,...,16 checks 16,383 root
candidates and 32,766 exponent candidates, including uniqueness.

Eight actual integers q=5^a, with a=1,3,5,9,17,49,113,625, are tested.
Group orders are computed by counting ordered independent GL columns,
then dividing by the determinant image and scalar centre. This differs
from the factored order expression in the proof. Degrees are computed
by a geometric quotient and compared with the polynomial. Every
group-order valuation is 13; at a=625 the degree valuation is 16.
Actual exit 0 and the arithmetic completion sentinel are recorded.

## Actual GAP module controls

One GAP 4.16.1 process, limited to a 4-GiB workspace, constructs the
projective actions of SL_4(3), SL_4(5) and SL_6(3). Their permutation
degrees are 40,156,364. The characteristic-two permutation modules
have composition dimensions [1,1,38], [1,1,154], [1,1,362]; GAP's
MeatAxe confirms every factor is absolutely irreducible. Actual
process exit 0, clean log and `PASS_1240_MODULES` are recorded.
The randomized search seed is fixed at 1240.

The small metadata output contains a GAP backslash-newline continuation
inside the seed 1240. The original bytes are retained, and the separate
decoded JSON removes only that continuation before parsing. The
auditor verifies this transformation. No module result was changed.

## Exploratory table screen

GAP's installed CTblLib 1.3.11 contains 2,750 queried ordinary-table
names. For all primes dividing the relevant group order, 7,573 Brauer
tables were available and 2,277 were unavailable. All 352,440 listed
degrees were independently checked using Python integer division.
Twenty-one table/prime rows contain 32 degrees exceeding the group-order
p-part. Aliases and isomorphic groups are not counted as distinct
mathematical examples. All raw degrees and all missing-table rows
are retained.

The first coverage audit stopped with actual exit 1 because Alt(2)
has order one and consequently has no prime-divisor row. The corrected
audit explicitly permits only this trivial-group case. The first
script and failure log were preserved. An archive naming error left
the first process JSON to be overwritten; its record was reconstructed
from the observed tool output and is marked as such. This reconstruction
is not represented as an untouched original file. The corrected audit
passes with actual exit 0. The screen itself passed on its original
run with actual exit 0, clean log and completion sentinel.

The full table screen is not a premise of the infinite proof, and no
claim is made about unavailable tables or groups outside the library.
