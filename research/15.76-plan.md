# Problem 15.76(b): working plan

Started 12 September 2026, approximately 01:06 UTC. Candidate count is
still 37. This lead is not counted until proof and source audits finish.

Target: for each fixed d>=1, the category of finitely generated free
groups in the variety S_d of all groups of derived length at most d has
only inner automorphisms. In particular this covers the full metabelian
variety S_2. No claim about every proper subvariety of S_d is intended.

1. Prove an associative-word rigidity lemma: a word w(x,y) that gives
   an associative operation with identity 1 in S_d equals xy or yx
   as an identity of S_d.
2. For d=2 use the two coefficient functions in the Magnus affine
   model. Associativity gives multiplicative equations; specialization
   to inverse cyclic elements forces two Laurent polynomials to be units.
3. Extend by induction on d using the group ring of a free S_(d-1)
   group. Preserve coefficient order carefully. The same cyclic
   specialization avoids any assertion about units of a noncommutative
   group ring. The boundary identity excludes the unwanted case when
   the scalar quotient is nonabelian.
4. Give the Magnus kernel argument using paths in the covering graph,
   so the only group-theoretic input is elementary graph fundamental
   groups and abelianization of their loop groups.
5. Reduce category automorphisms to these word operations explicitly:
   recognize rank one by its endomorphism monoid, normalize the coproduct
   basis maps, and reconstruct the underlying element bijections.
6. Check the reverse-multiplication case yields an inner functor, via
   the ordinary automorphism inverting each chosen basis element.
7. Search for prior associative-word and category results. Check the
   printed page visually and state the fixed-derived-length scope.
8. Run exact controls for the coefficient order, substitution, boundary
   identity, and induction with genuinely noncommuting scalar groups.
   Use finite controls as corroboration, not as proof of the infinite
   statements. Freeze a replayable packet only after internal review.

Critical risks: mistaking the full varieties S_d for all their
subvarieties; reversing a noncommutative coefficient product; assuming
an unproved group-ring unit theorem; assuming the category reduction;
or overlooking earlier literature. Each has an explicit check above.
