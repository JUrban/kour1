# Problem 6.47: bounded search for associative binary word operations

11 September 2026. Investigation, not a candidate solution.

The question starts with a word v(x,y) whose operation on a group G
defines another group G_v on the same set, and asks whether G_v belongs
to the variety generated by G. Basic necessary facts help constrain
a finite search: the identity and all integer powers are unchanged;
every original subgroup remains a subgroup for the new operation;
every original homomorphism remains a homomorphism for the new
operation. These facts alone do not settle arbitrary identities.

For a finite G, all binary word functions form the subgroup F generated
by the two coordinate functions in G^(G x G). Reduce the coordinate
set using Aut(G)-orbits of ordered pairs, retaining a transporter for
every pair. This reduction loses no word functions because words
commute with automorphisms.

If a word operation is a group operation, its identity is the original
identity: v(1,1)=1 is an idempotent. Its exponent sums in both variables
are 1 modulo exp(G), since v(x,1)=v(1,x)=x. Conversely these exponent
sums give the unit and inverse laws. In F the normalized functions are
exactly xy F': restriction to the two coordinate axes induces
F/F' = C_exp(G) x C_exp(G). The pilot will enumerate this coset when
its size is at most a stated cap and test every triple for associativity.

Start with six small groups, including nonabelian groups beyond class
two, using one extra GAP worker with the existing 4GiB ceiling. Each
job gets a separate timeout, actual process status, input and log.
Independently expand the orbit coordinates in Python and check the
unit, inverse, power and associativity conditions. A cap or timeout is
an omitted case, never a negative result.

For surviving operations, construct the actual group from the checked
table. Initial diagnostics can identify changes of nilpotency class,
derived length and isomorphism type. A nonisomorphic result alone is
not a counterexample: membership in var(G) needs a separate identity
or relatively free quotient certificate. In the two-generated case,
one can test whether the normalized new generators induce a quotient
of F, provided they generate G_v. This final variety-membership step
is not yet implemented or asserted.
