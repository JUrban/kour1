## Exact ring and root computations

The integral fourteen-dimensional adjoint Chevalley matrices are imported
from the frozen prime-field packet, with their source hash checked.
The new preparation independently checks the four finite ring operation
tables, root group laws, and every ordered nonopposite-root commutator.
As before, each commutator is factored by exhaustive lookup in a uniquely
parameterized ordered product of the roots ir+js, i,j positive. No
generic-characteristic coefficient is silently assumed nonzero.

For the three characteristic-two rings, elements are a+bt encoded by
a+2b, with addition XOR and respectively t^2=t+1, 0, t. The fourth ring
uses addition and multiplication modulo four. Divided powers are mapped
by the actual characteristic, so coefficients two remain visible in Z/4.

## Why the enumeration is exhaustive

The atoms are pairs (r,t) with t a nonzero ring element. There are 36
atoms. A set of atoms specifies root parameter sets with zero inserted.
Binary implications enforce closure under addition within a root.
Because these sets are finite, additive closure and zero also imply
closure under additive inverses.

For atoms (r,t),(s,u), add every factor consequence required when the
input parameter sets are the cyclic additive subgroups generated by t
and u. This is equivalent, in the presence of additive closure, to all
original carpet conditions. In one direction those cyclic subgroups
are contained in the input sets of a carpet; in the other direction
each actual pair t,u is among the tested pairs. Thus the implication-
closed sets are exactly the carpets.

The closure routine repeatedly adds consequences of satisfied binary
premises. It terminates, is extensive and monotone, and returns the least
closed superset. Closed sets are enumerated in lectic order. For each
current closed set A and each absent atom i in descending order, form
B = cl((A intersect {0,...,i-1}) union {i}); choose the first B whose
prefix below i equals that of A. To see completeness, let C be the next
closed set and let i be its first differing atom from A. The generated
B is contained in C and has that same differing prefix, hence lies
between A and C; minimality forces B=C. The descending trial order
selects the earliest possible next set. The empty closure starts the
enumeration and the full set ends it.

The implementation reproduces the exact sets of all 17,609 frozen C2
carpets and all 391 G2 prime-field carpets that were previously found
by brute force. Every newly emitted carpet is also checked against
the full original subgroup-level implication table. Neither the
million-carpet guard nor the orbit guard was reached.

## Faithful finite actions

The complete orbits of the second basis vector have degrees 4,095,
4,032, 3,969 and 4,032. For each characteristic-two ring the preparation
extracts fourteen orbit vectors with entries zero or one whose binary
matrix is invertible. Its inverse, computed over F2, works over the
ring as well. For Z/4 the selected matrix is invertible modulo two,
so its determinant is a unit in Z/4. A matrix fixing every orbit vector
therefore fixes a basis and is the identity. These are faithful actions
of the actual integral matrix groups reduced over each ring.

The separate control program verifies all four witnesses again by
Gaussian elimination over the actual ring. GAP computes ambient orders
251,596,800; 198,180,864; 146,313,216; and 198,180,864, matching the
field, local-ring and direct-product validation formulas. Faithfulness
comes from the spanning witnesses, independently of these order formulas.

GAP then generates the subgroup of every valid carpet, tests each of
the 48 root elements for membership, and checks the closure against all
factor implications. Search inputs remain hash-bound throughout the
run. The four workers and their controller all exit zero.

## Audit scope

The preparation auditor reproduces every input byte for byte and all
preparation data apart from elapsed time, and repeats the exact old
enumeration controls. The final packet auditor checks hashes, actual
exit observations, all search counts, every recorded enlargement and
the independent matrix results, and replays preparation and controls.
Logs and final observations are retained separately from manifests that
would otherwise hash themselves. The source construction is the same
standard Chevalley model imported in the prime-field report.

These four finite rings do not settle arbitrary rings in the exceptional
characteristics. The complete-candidate count remains 41. F9 is a
separate ongoing experiment and contributes nothing to this packet.
