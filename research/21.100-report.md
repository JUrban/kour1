# Problem 21.100: bounded coprime-action search

2026-09-12. **No counterexample found; the general problem is unresolved.**
This work adds zero complete candidates.

The 81, 243 and 729 pilot covers all involutions in the full automorphism
groups up to possible repetitions under conjugacy. The 256 and 2187
extension covers all nontrivial cyclic prime-power coprime actions, with
the same possibility of repetitions. For order 256 the observed action
orders are 3, 5 and 7; for order 2187 they are 2, 4, 8 and 13. There are
5,856 action rows with nonabelian fixed subgroup.

The catalogue loops visit all 65,988 group IDs in these five orders and
retain the 32,262 groups of class at least three. Some retained groups
have no actions in the specified range. Groups of smaller class were
omitted; no result about those omitted groups is claimed by this screen.
These are action-representative counts, not counts of distinct
isomorphism classes of semidirect products.

For a prime r coprime to |G|, every r-element of Aut(G) is conjugate into
a Sylow r-subgroup. Representatives of all nonidentity conjugacy classes
inside that Sylow subgroup therefore cover every cyclic r-power action.
Conjugate automorphisms have isomorphic fixed subgroups and equivalent
character tests. Duplicates under the larger automorphism group are
harmless. The pilot makes the same argument after restricting to order
two. Noncyclic acting groups and mixed-prime cyclic actions are outside
this coverage.

## Screen calculation and imported dependencies

GAP computes conjugacy classes and irreducible character tables. An
automorphism's class permutation identifies all invariant irreducibles.
The fixed subgroup is constructed directly from the fixed elements.
Every invariant character is evaluated on every class of that subgroup;
exact cyclotomic scalar products give every restriction multiplicity.
The script checks integrality, nonnegativity, degree reconstruction and
the unique constituent of multiplicity prime to r. It compares that
constituent's degree with the nonvanishing test and checks the count
against the fixed subgroup's abelianization order.

The classical identification of that constituent with the Glauberman
correspondent is imported. The source audit explains the already known
linear-correspondent implication. Thus the potentially new obstruction
in this range would be a nonlinear correspondent whose original
character never vanishes on the fixed subgroup. None occurred.

The full screen depends on GAP's SmallGroups catalogue, automorphism
groups, Sylow and conjugacy-class algorithms, character tables and exact
arithmetic. Reconciliation of the saved rows does not independently
prove those algorithms or the catalogue's completeness. The independent
controls below validate selected explicit actions only.

The pilot took about 73 seconds. Eight additional jobs, four residue
classes of catalogue indices per order, finished with actual return code
zero, empty stderr and exactly one completion marker each. Each used a
3 GiB GAP workspace cap. The final shard controller returned zero and
printed its eight-job completion marker. The unrelated 20.100 worker
continued undisturbed within the overall CPU and memory limits.

These are thirteen actions on twelve catalogue-labelled group models;
the two actions on (2187,8007) are certified separately. The chosen
actions have matching order, fixed-subgroup parameters and character
statistics in the saved screen. We do not assert equality of their
internal automorphism-class indices across separate GAP runs.

Each exported model consists of faithful generator permutations, a
labelled Cayley graph, the automorphism's permutation on all elements,
generators for the fixed subgroup, and inducing linear characters for
both G and its fixed subgroup. A packet for an inducing character lists
subgroup generators and the root-of-unity exponent at every element of
that subgroup. It contains no trusted irreducible-character table.

The Python verifier reconstructs the group from the faithful
permutations, proves all Cayley edges and distinctness of the labelled
elements, then reconstructs the multiplication table. Associativity
follows from the faithful permutation realization. It checks the
automorphism on every generator edge, its exact prime-power order, and
coprimality. Its fixed set must equal the generated claimed subgroup.
The derived subgroup is computed as the normal closure of generator
commutators, giving the abelianization order directly.

For an inducing subgroup H and proposed linear character lambda, every
generator edge verifies the additive root exponent. This proves lambda
is a homomorphism on all H. With right coset representatives t for H in
K, the verifier evaluates the genuine induced character by

    Ind_H^K(lambda)(g) = sum lambda(t*g*t^(-1)),

where the sum ranges over those representatives for which the argument
lies in H. Exact arithmetic takes place in Z[zeta_(p^a)] for p=2 or 3,
using the basis of degree (p-1)p^(a-1) and the explicit cyclotomic
relation. Thus there are no floating point zero tests.

Each induced character has norm one and so is irreducible. Their value
vectors are distinct; the sum of their squared degrees is the group
order, proving completeness by the regular-character decomposition.
The number of rows is also checked against the directly reconstructed
number of conjugacy classes. These standard character-theoretic facts
are the only proof ingredients for completeness; Conlon's output is
merely a source of candidate inducing data.

The verifier then reconstructs the invariant characters, all restriction
multiplicities, and the bijection defined by the unique multiplicity
prime to the action prime. For every nonlinear correspondent it saves
an explicit fixed element at which the original character is zero.
For every linear correspondent it checks every fixed conjugacy class.

Totals: 2,316 certified irreducibles in the ambient and fixed groups,
328 invariant characters, 120 nonlinear correspondents with zero
witnesses, 511,026 induced class values, 22,599,799 linear-homomorphism
edges, 78,775 faithful permutation edges, 78,775 automorphism edges,
17,320,818 multiplication entries and 10,304 restriction multiplicities.
Five deliberate corruptions are rejected: a Cayley edge, automorphism,
linear-character value at the identity, missing irreducible and missing
inducing generators. Catalogue names remain imported labels; the
positive character properties of the explicit models do not depend on
independent identification of those names.

## Rejected run and replay

The initial exporter failed its Conlon completeness check after writing
only part of the certificate. GAP itself exited zero, but stderr was
nonempty and the completion marker absent; its wrapper returned one.
Python was started prematurely against that incomplete file and
correctly rejected its JSON. Both scripts, outputs, process records and
the truncated file are preserved under `results/21.100-independent-initial`.

The reproducible duplicate-character and cache-order issue is detailed
in the source audit. The corrected exporter deduplicates Conlon's
output and verifies it against a standard basis computed first. The
accepted seven-model stage is separately frozen under
`results/21.100-independent-seven`; the final thirteen-model export and
independent verifier both returned zero with clean stderr and their
completion markers.

`scripts/audit_21_100.py` checks every packet hash, actual process record,
screen row, subgroup and character statistic, and preserved rejected
run. It re-exports the thirteen models into a temporary directory,
requires byte-for-byte certificate and log equality, reruns the Python
proof and corruptions, and replays the Conlon diagnostic. It does not
repeat the already completed full screen. Its first run rejected a
tuple-versus-JSON-list comparison in the summary before starting replay.
The summary now uses JSON-native lists; no screen result changed. That
rejected auditor and its exact evidence are retained under
`results/21.100-audit-initial`. Run the final audit with:

    python3 scripts/run_21_100_recorded.py audit

The packet is a bounded computational investigation and a collection of
explicit positive certificates. It supplies no proof for arbitrary
nilpotent groups or arbitrary coprime actions, and no new priority claim.
