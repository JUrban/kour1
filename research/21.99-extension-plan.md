# Problem 21.99: explicit word certificates and degree extension

2026-09-12. The existing search through degree 20 is preserved. No new
complete candidate is currently claimed.

For each transitive group G and every beta other than the first point,
find a word in the supplied generators that takes the first point to
beta and has a number of fixed points different from one. Store these
words as a shared multiplication/inversion circuit. An independent
verifier needs only to evaluate permutations and count fixed points;
it need not reconstruct conjugacy classes, subgroup orders or a base
and strong generating set. Transitivity then transports these
witnesses to every ordered pair of distinct points.

Construct point transversals as generator words by breadth-first search.
Schreier generators of the first-point stabilizer are then explicit
words. For a candidate word with fixed-point count other than one,
conjugation by point transversals and stabilizer words supplies witnesses
on the orbitals it meets. Try input generators and bounded random walks.
An uncovered point is an unresolved search case, not a counterexample;
it requires further exact investigation. Retain every actual process
exit, stderr, completion marker and case row.

Start with a pilot including all small transitive groups and large
selected degree-24 groups. Then process all catalogue groups in
non-prime-power degrees 21,22,24,26,28,30, partitioning the two largest
degrees across workers. If resources and time permit, extend to the
remaining installed non-prime-power degrees through 47.

An elementary proof settles arbitrary prime-power degree: choose a
Sylow p-subgroup containing a Sylow p-subgroup of a point stabilizer.
Its orbit has the full p-power degree. Every element has fixed-point
count congruent to the degree modulo p, so none has exactly one fixed
point. This is a partial result with priority unclaimed.

The author's 2026 paper, DOI 10.1007/s00013-026-02240-3, Remark 3(f),
states this question and distinguishes it from the stronger derangement
question. Source and reading scope will be documented before accepting
the packet. The failed exploratory use of GAP Factorization on a large
group reached its 4 GiB cap; no result from that probe is accepted.
