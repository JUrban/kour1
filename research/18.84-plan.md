# Problem 18.84: character-table screen

12 September 2026. Status: exploration, no candidate yet.

The question is whether BS_pi passes to normal subgroups. Test almost
simple pairs N normal in G. For an involution class C of a simple N,
the subgroup generated by x,y in C is dihedral. Thus the union of prime
divisors of orders of products xy, together with 2, is exactly the
smallest pi making every such pair generate a pi-group. If N is not a
pi-group, this class proves N is not BS_pi.

For G, use a sufficient certificate: every nonidentity pi-element class
has a square containing an element whose order has a prime outside pi.
Then no nonidentity class meets the antecedent of the BS_pi definition,
and G is BS_pi. This criterion may miss positive cases; failure is not
a proof that G fails BS_pi. For an almost simple G whose socle is not
a pi-group, O_pi(G)=1, but the criterion itself needs no radical input.

Class multiplication coefficients from an ordinary character table
decide which classes occur in C*C. Start with D4 triality and other
small exceptional automorphism cases. If a witness appears, separately
verify the normal pair, all source tables, the exact coefficients and
their formula, and reconstruct direct group controls where feasible.
The library tables are data, not independently proved character tables.
