# Problem 20.21: withdrawn claim, not a prior solution

12 September2026. The problem remains unresolved in this project.

A search found Ihechukwu Chinyere, *On the non-existence of finite
groups with certain normal subgroups*, arXiv:2601.01080, claiming
a negative answer. The primary current record
https://arxiv.org/abs/2601.01080 instead states that the paper was
withdrawn on7 January2026 because an error in Section3.4 affects
the main argument. The old abstract still appears in search results.
It must not be counted as a resolution.

The current metadata HTML is cached as
`references/cache/chinyere-2026-withdrawal.html`. The current PDF
request returned404. The explicitly requested v1 PDF was subsequently
downloaded as `chinyere-2026-normal-subgroups-withdrawn-v1.pdf`, with
layout text, and all five pages were read in text. No page images
were viewed. No theorem from this withdrawn paper is imported.

Section3.4 reduces its search to quotients C4 and V4, while the
appendix compares StructureDescription literally with the string
"V4". This does not provide a robust isomorphism check in GAP,
and the argument also introduces a non-characteristic-subgroup filter
without a justification shown there. The official withdrawal is
sufficient reason to reject the claimed conclusion; no corrected
proof is asserted here.

A separate Conder--Maslova proposition in the Ural workshop report
states that a minimal example has a normal2-subgroup of index3 and
a quotient C4 x A4 of order48. Its primary search excerpt was read,
but the report and reduction proof have not been fully inspected.
No finite search using that reduction has been started.
