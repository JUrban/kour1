# Problem 19.61: G2 over four-element rings

12 September 2026. Separate extension of the frozen prime-field pilot.

Test F4, F2[t]/(t^2), F2 x F2, and Z/4 in the same integral adjoint
Chevalley model. All ring axioms, root group laws, and individual
commutator factors are checked by exact finite arithmetic.

There are up to 5^12 = 244,140,625 assignments of additive subgroups.
Instead of scanning them all, use root-parameter atoms (r,t), t nonzero,
with binary implications encoding addition and every required individual
commutator factor. For a parameter t, its least additive subgroup is
generated by t, so the frozen subgroup implication table supplies exactly
the consequences of a pair of atoms once additive closure is imposed.
The closed sets of these implications are precisely the carpets.

The implementation starts with the closure of the empty set and uses
the usual lectic next-closure rule: for descending atom i absent from A,
close (A intersect {0,...,i-1}) union {i}; accept the first result whose
prefix below i agrees with A. This enumerates every closed set exactly
once. As controls, require exact set equality with all 17,609 C2 and
391 G2 prime-field carpets previously enumerated by brute force. Each
new emitted set is additionally checked against the full original
subgroup-level carpet conditions. A million-result guard is an explicit
failure, never a truncated negative result.

Use the complete orbit of the second basis vector under an additive
generating set of each root group, with a 10,000-vector guard. Require
an explicit fourteen-vector spanning witness: a binary invertible matrix
over characteristic-two rings, or an invertible reduction modulo2 over
Z/4. These certify a faithful permutation action on the actual matrix
group. Check the expected ambient order as an additional control;
the split and local-ring order formulas are validation hypotheses, not
substitutes for faithfulness or exhaustive subgroup membership.

Run the existing frozen root-subgroup search on each complete input.
Any failure needs an independent matrix/word certificate establishing
the original carpet and the offending closure parameters. If no failure
is found, retain a bounded negative result with independent controls
selected to include every observed kind of enlargement. Do not count
this finite extension as a solution to the general problem.
