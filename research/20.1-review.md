# Problem 20.1: internal proof audit

12 September 2026. This is internal review, not independent acceptance.

1. **Exact scope.** The original Notebook p.146 was read and viewed.
   The question requires a finite insoluble totally 2-closed group with
   nontrivial Fitting subgroup. It places no indecomposability restriction.
   The proposed group meets the literal question, and 20.1 is unstarred.
2. **Imported theorem.** Published Theorem 1.1 and Proposition 4.8 explicitly
   include J1. Its proof uses classification, base sizes, Atlas data and
   Magma calculations. Those inputs are not independently reconstructed.
3. **All actions.** The product lemma handles arbitrary faithful actions,
   including intransitive actions, repeated constituents and fixed points.
   Lemma 1 explicitly reconciles finite-set and arbitrary-set conventions.
4. **No transitive constituent assumption.** Neither factor is assumed
   faithful on any individual orbit. Faithfulness is proved on the entire
   set of the other factor's orbits.
5. **Singleton intersections.** CRT puts a into the cyclic subgroup of
   ab^{-1}. Since the latter fixes alpha, so does a. This uses commuting
   factors and coprime element orders. The V4 mutation fails precisely here.
6. **Quotient actions exist.** Both direct factors are normal, so the full
   group preserves each factor's orbit equivalence relation.
7. **The 2-closure preserves partitions.** These equivalence relations are
   unions of labelled orbitals. No claim that the 2-closure normalizes
   either factor is assumed or needed.
8. **Faithful quotients.** An element of A fixing every B-orbit moves a
   point inside the intersection in (1), hence fixes all points. The
   original action is faithful, giving a=1. The other factor is symmetric.
9. **Two independent blocks.** For every pair D,E of B-orbits, including
   D=E and blocks in distinct G-orbits, the point-pair witness ab induces
   the required A-witness. This is the full pair criterion on Delta_B.
10. **One global factor element.** Total 2-closure on the quotient set
    supplies one a0 for all B-orbits simultaneously. It is not a separately
    selected element for each original orbit. Cross-orbit controls test this.
11. **Recombination.** B acts trivially on its orbit set and A on its own.
    Therefore a0b0 has both prescribed quotient actions. The common kernel
    fixes all singleton intersections, so is trivial.
12. **Prime cyclic input.** A faithful C_p action has a point with trivial
    stabilizer. Anchoring each ordered pair there proves 2-closure directly,
    for any cardinality of the action set.
13. **Finite-set transfer.** The finite faithful subset contains witnesses
    for all nonidentity elements. Every element of the 2-closure preserves
    it, as it preserves each point orbit. Uniqueness on that subset forces
    agreement on each added orbit. No compactness claim is used.
14. **Order and Fitting subgroup.** 13 is coprime to 175560. Projection of
    a normal nilpotent subgroup is normal and nilpotent. The simple J1
    projection is trivial; the central C13 supplies equality, not just
    inclusion in the Fitting subgroup.
15. **Numerical role.** The 177 bounded finite actions are controls of the
    argument, not an exhaustive certificate of total 2-closure of J1 or of
    the example. All conclusions for arbitrary actions rest on the proof.
16. **Independent enumeration.** Python reconstructs factor groups from
    generators, builds ordered-pair colours from every group element and
    exhaustively enumerates colour-preserving bijections. Its output agrees
    exactly with GAP, which instead intersects orbital stabilizers inside
    a product of transitive 2-closures.
17. **Negative controls.** Shared-prime V4 has closure order eight; removing
    cross-orbit constraints enlarges diagonal C3 to order nine. Non-totally
    closed S3 and A4 factors yield respectively 14 and 34 enlarged cases.
18. **Execution evidence.** Both final control processes actually exit zero
    with clean logs and sentinels. The two initial GAP API failures remain
    archived and are excluded from positive evidence.
19. **Priority.** Located Chen--Ren Theorem C assumes nilpotence, and its
    concluding direct-product observation concerns a specified disjoint
    action. Neither is the general lemma above. Initial searches found no
    exact prior example, but this is not a certification of novelty.

No internal mathematical gap was identified. The substantial J1 input
and unconfirmed priority remain explicit limits of the packet.
