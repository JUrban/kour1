# 18.114: irreducible 5-prime linear groups attaining k(VG)=|V|

Date: 2026-09-11. Search complete; no candidate solution.
The printed question was visually checked on supplied PDF page130.

The question asks for a noncyclic irreducible subgroup G of GL_n(5)
whose order is prime to 5, with exactly 5^n conjugacy classes in its
affine semidirect product V semidirect G.

## Literature and scope

Schmid, *Signed permutation modules, Singer cycles and class numbers*,
J. Group Theory 14 (2011), 175–199,
https://doi.org/10.1515/JGT.2010.048 , has a primary publisher abstract
which classifies equality when p>5 and explicitly leaves p=5 open.
The full paper was located but not audited. The earlier 2005 paper,
*Some remarks on the k(GV) theorem*, DOI 10.1515/jgth.2005.8.5.589,
was screened through author-uploaded excerpts. No general equality
classification for characteristic 5 was located in the initial search.
This does not establish current open status or novelty.

## Initial exact computation

Use IRREDSOL 1.4.6 to enumerate every irreducible soluble subgroup
of GL_n(5), up to matrix conjugacy, for n=1,...,6. Enumerate all
splitting-field degrees dividing n, so groups which are not absolutely
irreducible are included. F5 has no proper subfield requiring an
additional trace-field sweep. Filter by 5 not dividing |G|.

For a noncyclic eligible group, construct its actual affine pc group
and compute its exact class number. For cyclic G, use the elementary
fixed-point-free formula |G|+(5^n-1)/|G|; these cases provide equality
controls and are outside the requested noncyclic class. Log every
eligible library identifier, complement order, class number, and cost.

Three runs partition dimensions as 1–3,4,5–6. Each uses one CPU and
a GAP workspace cap of 4GB. Together with the existing live search,
this is below the user's CPU and memory limits. No dimension or order
cutoff is silently skipped within these ranges. An unavailable entry
is an error, not a non-hit.

Independent controls will construct small affine permutation groups
directly from matrices and translations, count conjugacy classes,
and compare with the pc-library calculation. Include known noncyclic
equality examples over F2 and F3 so the search predicate has positive
controls. A hit requires independent irreducibility, coprimality,
noncyclicity, and class-number certification before any claim.

Even a completed negative run covers only soluble groups in dimensions
at most 6. It is not a general negative answer to 18.114.

seven equality controls, all cyclic: the trivial group in dimension1

The first attempted runs used the indexed PrimitivePcGroup(n,p,d,k)
constructor. Its cached guardian data can belong to a different
complement. A fresh-session diagnostic gives:

    ID (2,5,1,1): |G|=32, indexed affine order800, required800.
    ID (2,5,1,6): |G|=48, indexed affine order800, required1200.

The source stores the guardian using only (n,q), while the selected
guardian also depends on the descriptor of the requested group.
The old logs are preserved as *-invalid-cache.log and excluded from
all results. The running invalid dimension6 job was stopped.

Every valid run instead calls
PrimitivePcGroupIrreducibleMatrixGroup(g) on the selected matrices
and asserts the affine order5^n|G|. The diagnostic gives1200 for the
second group using this constructor. No package source was changed.

Independent controls build actual affine permutation groups on all
vectors for every coprime IRREDSOL entry over p=2,3,5 and n<=3.
Fresh matrix-module irreducibility tests, actual complement orders
and cyclicity, and conjugacy-class counts agree in all57 cases.
Three noncyclic equality examples over the smaller fields provide
positive controls. For37 cases with complement order at most32,
a third calculation sums p^dim C_V(x,y) over all commuting pairs
(x,y) in G and divides by |G|; it agrees as well.

For this formula, a commuting linear pair has p^(n+c) commuting
affine lifts, where c=dim C_V(x,y). The image of the linear equation
for the translation parts is [V,<x,y>], of codimension c by coprime
semisimplicity. Dividing the total number of commuting affine pairs
by p^n|G| proves the formula.
