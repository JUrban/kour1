# A possible square-completion route to 19.61

12 September 2026. General 19.61 remains unresolved at the start of
this experiment. The rank-two 19.62 theorem is frozen at 43d51dd.

Test whether adjoining a single element a^2 b to A_r, with a in A_r
and b in A_-r, preserves both the carpet conditions and the derived
carpet B. For every original commutator rule with sources r,s, replacing
its first argument x by x+n a^2 b expands into monomials

    c binomial(i,k) x^(i-k) a^(2k) b^k u^j, 1 <= k <= i.

Here x,a are independent elements of A_r, b belongs to A_-r and u
belongs to A_s. The coefficient n^k is harmless in an additive subgroup.
All root labels lie in the plane of r,s. Check every such target in
A2, B2 and G2 for membership in the original B_(ir+js). Both arguments
of each original ordered rule must be changed separately, retaining
that rule's original constant: reversing a source pair can change a
G2 constant. The initial first-argument-only pilot is retained, but
the complete preparation includes both arguments and strengthens 36
G2 coefficients without adding new target monomials.

If every target is certified, each single adjoining step leaves the
derived family unchanged, and therefore remains a carpet. Iterating
the operation and taking directed unions should give a carpet C
containing A, satisfying C_r^2 C_-r inside C_r, and with derived carpet
equal to B. The known closedness criterion would make C closed. Thus
the root closure D of A lies between A and C, and every commutator
factor for D lies in derived(C)=B, which is contained in A and hence
D. That would answer 19.61 affirmatively. Every step of this proposed
completion argument still requires proof; a failed monomial search
would only reject this sufficient route, not the original problem.
