# Bounded finite subgroups: report

2026-09-12. Additional partial result for 20.89 / 19.83; complete
candidate count remains 46. Outside review and priority remain pending.

The proof gives a characteristic common finite sink for all almost
Engel elements of a linear group whose finite subgroups have uniformly
bounded order. For a torsion-free subgroup of index d, the exhibited
kernel has order dividing d. This covers every characteristic without
assuming finite generation or a normal torsion-free subgroup.

The mathematical input is the already committed local
finite-by-nilpotent reduction in `20.89-residual-reduction.md`. Its
Malcev, Gruenberg, and Shumyatsky dependencies retain exactly the source
scope recorded in `20.89-source-audit.md`. The torsion-subgroup step is
also proved in `20.89-char0-proof.md`, Lemma 2; the new note repeats it
to make the bounded-order deduction independently readable. The coset
divisibility argument and the two matrix examples are proved directly.
No additional external theorem is needed.

The review checked the following substantive issues in the written
argument: finite-by-nilpotence passes to subgroups; torsion elements
generate finite subgroups before any bound is used; the finite kernel
is characteristic in the entire ambient group; and the common sink
works for arbitrary ambient test elements. The index argument uses a
free finite-group action on cosets and does not assume the given
torsion-free subgroup is normal.

There is no new GAP computation underlying this elementary infinite
argument. A native GAP startup check in this turn returned version
4.16.1 with process exit 0. The S_3 times Z and Laurent-polynomial
matrix examples are algebraic controls with proofs in the note. No
claim of an independently executed matrix experiment is made.

The evidence manifest binds the authored notes and the existing
mathematical dependencies. Mutable portfolio and status summaries are
