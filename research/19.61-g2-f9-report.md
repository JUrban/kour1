# Problem 19.61: exhaustive G2(F9) search

12 September 2026. Bounded negative result, not a general solution.

All **40,105** carpets over F9 in the G2 adjoint Chevalley model have
carpet closures. Exactly **4,032** closures are larger than their
initial carpets; none fails a carpet factor condition.

## Exhaustive preparation and action

F9 is represented as F3[t]/(t^2+1), with a+bt encoded by a+3b. Its six
additive subgroups give 6^12 possible assignments. The finite implication
closure enumeration, previously verified against 18,000 brute-force
cases, enumerates exactly the valid carpets. Ring arithmetic, root group
laws and every commutator factor are checked by actual fourteen-by-
fourteen matrices. Unique factorization in the specified ordered products
is verified by enumerating all coefficient tuples, retaining the
characteristic-three degeneracies exactly.

The invariant seven-dimensional module is derived from the frozen F3
orbit span. Every restricted root action is reconstructed exactly in the
fourteen-dimensional representation. The projective orbit of the line
of the second basis vector is complete and has 66,430 points. Its
faithfulness follows from the precise construction and simplicity
argument in `research/19.61-g2-projective-faithfulness.md`: the original
adjoint group over F9 is simple, and an explicitly checked root element
moves that projective point. The reduced Lie algebra need not be simple
for this argument. The relevant Chevalley group theorem is imported
from Steinberg's primary lecture notes, with the exact reading scope
recorded separately.

GAP verifies the ambient order 22,594,320,403,200. The order check is
additional validation, not the faithfulness proof. A separate preparation
audit regenerates the complete input byte for byte and compares every
preparation datum apart from elapsed time; it exits zero.

The independent matrix program checks all carpets supported on at

This program uses the full fourteen-dimensional matrices without the
permutation action, and independently reconstructs every restricted
root action on the seven-dimensional module. It shares the verified
root/ring data with the preparation, so it is a separate membership
calculation, not an independent source of the Chevalley model.
