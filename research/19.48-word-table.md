# Problem 19.48: explicit matrix word

Encode a+bj as a+3b, with j^2=2 and a,b in {0,1,2}.
U=(1,1,0,1), V=(1,0,4,1); lowercase letters denote inverses.
Read the word VUVuVUvuv from left to right. Each tuple gives
the four entries of the prefix matrix by rows.

| Prefix | Matrix |
|---|---|
| identity | (1, 0, 0, 1) |
| V | (1, 0, 4, 1) |
| VU | (1, 1, 4, 5) |
| VUV | (5, 1, 5, 5) |
| VUVu | (5, 8, 5, 0) |
| VUVuV | (8, 8, 5, 0) |
| VUVuVU | (8, 4, 5, 5) |
| VUVuVUv | (2, 4, 4, 5) |
| VUVuVUvu | (2, 5, 4, 1) |
| VUVuVUvuv | (1, 5, 0, 1) |

The final matrix is I+(2+j)E12. Its parameter is outside F3.
