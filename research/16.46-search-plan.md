# A bounded finite-quotient search for Problem 16.46

11 September 2026. General problem unresolved; no candidate solution.

The presentation on printed Notebook page 101 has six generators, with
A and B of order dividing three, C,D,E,F of order dividing two, eight
cube relations and eight additional square relations. All 22 relators
are transcribed literally in `scripts/search_16_46.g`.

In the abelianization, X^2=(AX)^3=A^3=1 forces X=1 for
X=C,D,E,F. The remaining square relations force A=B=1. Thus K is
perfect, and every nontrivial finite quotient has a nonabelian simple
quotient. Moreover any nontrivial homomorphism from K has images A,B
of exact order three and C,D,E,F of exact order two. If A or B is
identity, the cube relations kill all four involutions and a square
relation kills the other generator. If an involution image is identity,
its square relations force both A and B to be identity.

For a fixed finite target G, conjugate A to one representative of each
order-three conjugacy class and enumerate every order-three element B.
For each pair form

    I={X : |X|=2, (AX)^3=(BX)^3=1}.

There are four independent conditions on elements of I:

    C: (ABA^-1 X)^2=(BAB^-1 X)^2=1;
    D: (ABA^-1 X)^2=(B^-1AB X)^2=1;
    E: (A^-1BA X)^2=(BAB^-1 X)^2=1;
    F: (A^-1BA X)^2=(B^-1AB X)^2=1.

The target admits a nontrivial homomorphism if and only if, for some
pair A,B, each of these four sets is nonempty. The four involutions
may coincide; distinctness is not a relation. There are no relators
mixing two of C,D,E,F, so choosing them independently is exact. A
positive result will be checked against the full presentation in a
separate implementation before any resolution is claimed.

The initial bounded scope is alternating groups A5 through A8 and
PSL2(q) for prime powers 4<=q<=31. Some targets are isomorphic; they
remain useful distinct constructions but are not counted as distinct
simple groups. For a negative result this only excludes the listed
targets. It does not prove that K has no nontrivial finite quotient.
