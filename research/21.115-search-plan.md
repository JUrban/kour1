# Exact search for a finite coset-union counterexample

**Archived before the group search began.** A further literature check
found the general resolution arXiv:2609.09052v1 (8 September 2026).
The source argument was inspected; see `21.115-literature-audit.md`.
The scripts and model controls are retained for reproducibility and possible
reuse. Exporting cosets does not itself check the conjecture. No negative
group-search range is claimed.

Notebook 21.115 asks whether a proper union of n left or right subgroup
cosets in a finite group G always misses at least |G|/2^n points.
The special-case proof in `21.115-partial-proof.md` is kept separate.

Translate an uncovered point to 1. Translation preserves subgroup cosets,
and every left coset can also be written as a right coset of a conjugate
subgroup. Thus it suffices to enumerate all right cosets avoiding 1.
Any such coset contained in another can be discarded: enlargement still
avoids 1 and can only decrease the complement. This reduction must use
actual coset containment; taking only maximal subgroups is insufficient.

For fixed n, failure means at most T=ceil(|G|/2^n)-1 uncovered elements.
Associate a Boolean y_C to each retained coset and a Boolean z_g to each
g != 1. Impose

    sum_C y_C <= n,
    z_g + sum_(C containing g) y_C >= 1,
    sum_(g != 1) z_g <= T-1.

Feasibility is equivalent to a counterexample with at most n cosets. A
smaller family can be padded by repetitions if exactly n is desired. The
identity is an additional, implicit uncovered element. The inequality is
strict: equality at |G|/2^n is not a failure. Values with 2^n >= |G| are
automatic because a proper complement has at least one point; n=1 is
automatic because a proper subgroup has index at least two.

`scripts/export_21_115.g` exports all actual cosets from every actual
subgroup in GAP, skipping abelian groups and the proved odd-derived
class-two case. `scripts/search_21_115.py` applies containment reduction
and the OR-Tools CP-SAT model. INFEASIBLE is bounded negative evidence;
UNKNOWN is a timeout or otherwise inconclusive and is always retained.
Every feasible solution is checked by integer set arithmetic, then must
be independently certified as actual subgroup cosets in GAP before any
mathematical counterexample is claimed.

The model is independently compared with exhaustive subset selection on
small set systems, including feasible examples and threshold equalities.
Initial range: nonabelian groups through order 64, with a ten-second limit
per (group,n) and bounded concurrent CPU allocation. Broaden adaptively.

Solver installed locally with `python3 -m pip install --target
software/coset-python ortools`; installed version and dependencies are
recorded in `results/coset-solver-requirements.txt` and the installation log.
Official API references inspected:
https://developers.google.com/optimization/cp/cp_solver and
https://developers.google.com/optimization/cp/cp_tasks .
