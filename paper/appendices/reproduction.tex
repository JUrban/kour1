\section{Artifacts and reproduction}
\label{app:reproduction}

The configured repository address is
\url{https://github.com/JUrban/kour1}.
Anonymous access could not be established during manuscript
preparation: unauthenticated API requests returned HTTP~404.
A local Git query obtained a remote head different from
the frozen experimental revision. These observations
do not establish that either revision is anonymously
available or that the two histories are equivalent.
Readers need the frozen archive identified in
Appendix~\ref{app:protocol} to reproduce repository-based
measurements. The mathematical exposition in the paper
does not require executing that archive.

The main entry points in the archive are
\artifact{reports/FINAL_REPORT.md},
\artifact{reports/REVIEW_GUIDE.md}, and
\artifact{research/complete-candidate-ledger.json}.
The last file records the transcribed question, covered
parts, proof paths, review paths, and evidence entry
points for every candidate. The original PDF remains
authoritative if an extraction differs from its typography.

The later \artifact{paper/} directory contains manuscript
source, generated measurements, and a review ledger.
From the repository root, the measurement command is
\begin{quote}\small
\texttt{python3 paper/scripts/analyze\_experiment.py --check}
\end{quote}
It uses Python's standard library and Git, reads the
supplied HTML and text exports, and recomputes the
statistics from the frozen history. It checks agreement
with committed outputs rather than modifying them.
Without \texttt{--check}, it regenerates the five
measurement files.

Raw session exports are supplied evidence separate from
the paper's source bundle. Their hashes and sizes allow
an authorized holder to identify the exact inputs.
The visible-message projection is not a substitute for
the omitted raw tool events. Mathematical scripts
likewise have different purposes: some generate examples,
some check certificates, and some summarize existing
results. Reproducing a summary is not rerunning a proof
check. Each result's archive entry identifies its
commands and the limits of the computation.

Large computations need substantial time and storage.
In particular, the \(n=7\) certificate for \kn{20.100}
is distinct from smaller diagnostic and intermediate
files. The retained report and manifest specify the
complete input and all completed checker shards.
The manuscript's review does not silently replace that
historical verification with a fresh abbreviated run.

The portable source includes the complete integer derivations for
Problems~19.61--19.62, their target-coverage checkers, and the integral
\(G_2\) matrix-identity check. In the arXiv source archive these are
under \artifact{anc/}; in the full manuscript project they are under
\artifact{ancillary/}. Their README gives three standard-Python
commands, which require neither GAP nor network access. A manifest
binds the 23 original files to their byte-identical research versions.
The 19 short representative derivations are also printed above.

The main file is \artifact{main.tex}. The source archives include
\artifact{main.bbl} and the compiled chronology figure, so ordinary
XeLaTeX/BibTeX or Tectonic can typeset the paper without regenerating
the data or running mathematical computations. The full-source archive
additionally contains the aggregate measurements, the frozen candidate
ledger, figure source, build scripts, and manuscript review records.
Recomputing the original session/Git measurements still requires the
separately retained experimental archive and session inputs.
