\begin{abstract}
We report a single, time-bounded experiment in which a general-purpose
coding agent was asked to investigate previously unsolved problems in
the Kourovka Notebook. The agent used GPT-6 Astra with \texttt{xhigh}
reasoning, a local GAP installation, exact auxiliary programs, access
to mathematical literature, and a persistent Git repository. It chose
its own targets and alternated symbolic arguments with finite searches,
counterexample construction, source checking, and revision. The
48-hour deadline archive contains 46 entries labeled complete solution
candidates, together with partial theorems, rediscovered arguments,
deductions from prior results, and bounded negative searches. This
number describes the agent's documented outcome; it is not a count of
independently accepted new theorems. We present mathematical arguments
and their dependencies, reconstruct the observable trajectory from
a timestamped session log and 199 local commits, and distinguish mathematical
verification from artifact integrity and priority assessment.
The case study illustrates both the productivity of a persistent
tool-using workflow and the review obligations it creates. It supports
recommendations for future experiments, including separate novelty and
correctness ledgers, independent checking of search predicates, explicit
coverage boundaries, and preservation of failures and resource records.
Reconciliation of the detailed usage log
also separates research from later writing and identifies compaction
requests omitted from the session summary counters.
\end{abstract}
