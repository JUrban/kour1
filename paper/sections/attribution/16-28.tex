Jayadevan~\cite{jayadevan-16-28} gives a different triangular-matrix
example in \(\GL_3(\overline{\F_5(u)})\). His closed set contains
the identity and has one diagonal matrix omitted from every higher
power but lying in each closure. Both constructions use characteristic
five and a transcendental marker; see Appendix~\ref{app:contemporary-comparison}.
