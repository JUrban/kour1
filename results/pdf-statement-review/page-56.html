Chernikov 11.115. Suppose that X is a free non-cyclic group, N is a non-trivial normal subgroup of X and T is a proper subgroup of X containing N . Is it true that [T, N ] < [X, N ] if N is not maximal in X? V. P. Shaptala 11.116. The dimension of a partially ordered set ⟨P, ⩽⟩ is, by definition, the least cardinal number δ such that the relation ⩽ is an intersection of δ relations of linear order on P . Is it true that, for any Chernikov group which does not contain a direct product of two quasicyclic groups over the same prime number, the subgroup lattice has finite dimension? Expected answer: yes.
