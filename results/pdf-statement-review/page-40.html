Silberger (Proc. Amer. Math. Soc., 96, no. 1 (1986), 23–28) proved that there exists a number N 0 = N 0 (c) such that the word x r y s , rs ̸ = 0, is universal on the alternating group A n for any n ⩾ max {N 0 , c · log m(r, s)}, where m(r, s) is the product of all primes dividing rs if r, s ̸∈ {−1, 1}, and m(r, s) = 1 if r, s ∈ {−1, 1}.
