We say that a product XY = {xy | x ∈ X, y ∈ Y } of two subsets X, Y of a group G is direct if for every z ∈ XY there are unique x ∈ X, y ∈ Y such that z = xy. Is there an infinite group G such that every subset A ⊆ G satisfies the following property: all the maximal subsets B for which the product AB is direct have the same cardinality? Note that for checking the property for a given infinite group G, it suffices to consider only those subsets A ⊆ G for which |A| = |G \ A|. Indeed, the property is equivalent to A −1 A ∩ BB −1 = {1} and A −1 AB = G, and these imply |G| = |A||B|, since G is infinite. Now, if |A| < |G \ A|, then |A| < |G|, and so |B| = |G|; and if |A| > |G \ A|, then A −1 A = G, and so |B| = 1, for all B satisfying the property. M. H. Hooshmand ∗ No, there are no such groups (M.
